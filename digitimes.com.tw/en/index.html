When submarine cables fail, can digitimes.com.tw still load normally?

Based on the latest test, under a submarine-cable outage scenario the availability of digitimes.com.tw is “uncertain.” If international connectivity is cut or blocked, we cannot confirm whether the site would remain available.

Why is it “uncertain” whether digitimes.com.tw would work when submarine cables fail?

We did not see direct requests to foreign resources, but we did find reliance on in-country nodes of multinational cloud services. Whether those services keep running when outbound connectivity is impaired depends on platform architecture, cache design, origin routing, and more—so for now we can only label the outcome “uncertain.”

Does this mean digitimes.com.tw might be unavailable during severe cable congestion?

“Uncertain” means we currently cannot conclude it will definitely work or definitely fail. Availability of the multinational cloud in-country nodes that digitimes.com.tw depends on, when cables are cut or congestion is extreme, needs to be clarified and explained further by providers.

How is resilience for digitimes.com.tw under cable outages assessed?

When opening the homepage of digitimes.com.tw, we observed 166 requests across 19 domains.
If any involve connections abroad, the outcome is classified as “Will not work.” If there are no foreign connections but there is reliance on in-country nodes of multinational cloud services, the outcome is “Uncertain.” If connections are only domestic aside from that international-cloud pattern, the outcome is “May work.”
